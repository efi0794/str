# HoYo Daily Status\n\n崩壊：スターレイル / 原神 / ゼンレスゾーンゼロ の日課を1画面で確認する非公式ダッシュボードです。\n\n毎日 21:00（Asia/Tokyo）に、明確に未完了と判定できるゲームがある場合だけ Discord Webhook へ通知します。\n\n## できること\n\n- 3ゲームをカードで一覧表示\n- HoYoLAB認証状態\n- スターレイル: デイリー訓練 / 開拓力 / 派遣\n- 原神: デイリー依頼 / 天然樹脂 / 探索派遣 / 洞天宝銭\n- ゼンゼロ: 活躍度 / バッテリー / スクラッチ / ビデオ屋\n- 各ゲームのHoYoLABログインボーナス状態\n- 21時に未完了ゲームをDiscord通知\n- 判定不能を未完了と誤認しない\n\n> HoYoverse / COGNOSPHERE の公式アプリではありません。HoYoLABの非公式APIを利用します。\n\n## セットアップ\n\ngit clone https://github.com/efi0794/str.git\ncd str\nnpm install\ncopy .env.example .env\n\n.env を編集します。\n\nHOYO_LTOKEN_V2=xxxxxxxx\nHOYO_LTUID_V2=123456789\nHSR_UID=800000000\nGENSHIN_UID=800000000\nZZZ_UID=13000000\nDISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...\nPORT=3000\n\n遊んでいないゲームのUIDは空欄でOKです。\n\n## HoYoLAB認証情報\n\n1. ブラウザでHoYoLABへログイン\n2. F12 → Application\n3. Storage → Cookies → HoYoLAB\n4. ltoken_v2 と ltuid_v2 を確認\n5. .env にコピー\n\nHoYoverseのパスワードそのものは入力しないでください。.env は .gitignore 済みです。\n\n## Discord Webhook\n\nDiscordの通知先チャンネルで チャンネル設定 → 連携サービス → ウェブフック → 新しいウェブフック と進み、URLを .env の DISCORD_WEBHOOK_URL に設定します。\n\nサーバーを常時起動しておけば、毎日21:00 JSTに自動チェックします。\n\n### 通知ルール\n\n- 1つ以上のゲームが明確に未完了 → 通知\n- 全ゲーム完了 → 通知なし\n- APIからデイリー状態を判定できないだけ → それだけでは通知しない\n- 未完了ゲームがある場合、判定不能や取得失敗も通知本文に併記\n\n## 起動\n\nnpm start\n\nブラウザで http://localhost:3000 を開きます。\n\n## 重要: 「ログイン」の意味\n\nこのアプリの「認証OK」は HoYoLAB APIへ認証済みでアクセスできる状態 を意味します。ゲームクライアント自体が今起動しているか、今日PCでゲームを起動したか、という判定ではありません。\n\n## API\n\n- GET /api/status — 3ゲームの正規化済みステータス\n- GET /api/health — 設定・サーバー稼働状態\n\n## 注意\n\nHoYoLAB側のAPI仕様は公式公開APIではなく変更される可能性があります。特にスターレイルのデイリー訓練値は、API応答によっては「判定不能」と表示されます。この場合は未完了扱いにしません。
